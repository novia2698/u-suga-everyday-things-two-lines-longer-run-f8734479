A tiny Node program that writes a two-line explanation of a traffic jam to `/output/entry.txt`: line 1 explains it to a 10-year-old through one concrete, surprising analogy (a garden hose with a kink in it — cars are water piling up behind the bend), and line 2 says honestly what that analogy maps and what it leaves out. Built for make.fun's "Everyday Things, Two Lines, Longer Run" bounty, winner-takes-all $2 in USDC. The program checks its own output against the gate (1–400 characters, exactly two lines) before writing.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
